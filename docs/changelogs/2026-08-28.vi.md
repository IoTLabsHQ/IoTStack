# 28/08/2026

## Có gì mới

- **Theo dõi tài nguyên.** Trang Resources mới hiển thị CPU, RAM, disk trực tiếp cho cả server lẫn từng service của IoTStack, kèm lịch sử theo ngày, tuần, tháng, năm. Ngưỡng cảnh báo (warn/critical) chỉnh được, báo trước trên Overview để bạn không bị bất ngờ. Một agent nhỏ chạy trực tiếp trên host (tự cài đặt) để thấy được usage thật, vì các container của app không thấy được.
- **Control Panel.** Mỗi thiết bị giờ có trang Control riêng — gắn widget vào field telemetry hoặc status thật (giá trị cảm biến, công tắc relay) để xem/điều khiển thiết bị mà không cần đọc JSON thô. Cấu hình control ngay trên trang, qua chế độ Edit.
- **Đã sửa:** control có thể hiện giá trị cũ khi 2 tin nhắn đến cùng trong 1 giây — thứ tự tin nhắn giờ phân biệt thêm bằng id, không chỉ dựa vào timestamp.
- **Dự án mẫu Quick Start, luôn dùng MQTT bảo mật.** Wizard "Chạy thử dự án mẫu" mới trên Overview đi từ con số 0 tới một thiết bị thật kèm control khớp sẵn và code nạp sẵn, chỉ vài cú click. Code Arduino sinh ra — từ wizard này lẫn trình tạo code theo thiết bị — giờ luôn kết nối qua MQTTS (TLS), không còn plain MQTT.
- **Tên thiết bị Quick Start gọn hơn.** Thiết bị tạo từ template giờ đặt tên `<Tên template> - <Tên board>` đúng theo ngôn ngữ dashboard đang chọn, tự thêm số thứ tự (`- 001`, `- 002`, …) nếu tên đã tồn tại.
- **Trạng thái online của thiết bị trên trang Control.** Hiện chỉ báo "Online · Ns/phút/giờ/ngày trước" theo tin nhắn gần nhất của thiết bị, tự cập nhật không cần tải lại trang.
