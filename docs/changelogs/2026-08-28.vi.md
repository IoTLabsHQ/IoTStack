## Có gì mới

- **Theo dõi tài nguyên.** Trang Resources mới hiển thị CPU, RAM, disk trực tiếp cho cả server lẫn từng service của IoTStack, kèm lịch sử theo ngày, tuần, tháng, năm. Ngưỡng cảnh báo (warn/critical) chỉnh được, báo trước trên Overview để bạn không bị bất ngờ. Một agent nhỏ chạy trực tiếp trên host (tự cài đặt) để thấy được usage thật, vì các container của app không thấy được.
- **Control Panel.** Mỗi thiết bị giờ có trang Control riêng — gắn widget vào field telemetry hoặc status thật (giá trị cảm biến, công tắc relay) để xem/điều khiển thiết bị mà không cần đọc JSON thô. Cấu hình control ngay trên trang, qua chế độ Edit.
