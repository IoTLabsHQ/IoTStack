# 26/08/2026

## Có gì mới

- **Cài đặt bằng một lệnh duy nhất.** Cài IoTStack lên server Linux mới chỉ với một script. Chạy lại trên bản đã cài sẵn sẽ hỏi bạn có muốn cài lại sạch, kèm tùy chọn giữ nguyên domain và chứng chỉ SSL hiện tại.
- **Triển khai tự động.** Deploy hoặc cập nhật server chỉ với một lệnh từ máy tính của bạn, đã bao gồm HTTPS.
- **Tùy chỉnh domain & email ngay trên dashboard.** Cấu hình domain (tự động có HTTPS) và email gửi đi trực tiếp từ trang Settings — không cần truy cập server.
- **Công cụ quản lý thông tin thiết bị.** Sao chép hoặc tải về (CSV) thông tin kết nối của thiết bị ngay sau khi tạo, không lo bị mất.
- **Trình tạo code Arduino.** Chọn board ESP32 và một mẫu code (nhấp nháy đèn, điều khiển relay, hoặc cảm biến nhiệt độ/độ ẩm), rồi tải về code đã điền sẵn thông tin thiết bị, sẵn sàng nạp vào board. Có thể tải bất cứ lúc nào từ trang chi tiết thiết bị.
- **Cải thiện độ ổn định.** Triển khai lại server không còn rủi ro mất cấu hình.
