# August 26, 2026

## What's new

- **One-command installer.** Set up IoTStack on a fresh Linux server with a single script. Running it again on an existing install safely offers a clean reinstall, with the option to keep your current domain and SSL certificate.
- **Automated deployment.** Deploy or update your instance from your own computer with one command, HTTPS included.
- **Custom domain & email, from the dashboard.** Configure your domain (with automatic HTTPS) and outgoing email directly from Settings — no server access needed.
- **Device credential tools.** Copy or download (CSV) a device's connection details right after creating it, so you never lose them.
- **Arduino code generator.** Pick your ESP32 board and a sample sketch (blink, relay control, or a temperature/humidity sensor), then download ready-to-flash code with your device's credentials already filled in. Available anytime from a device's page.
- **Reliability improvements.** Redeploying your server no longer risks losing its configuration.
